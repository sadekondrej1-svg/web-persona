Je mi 19 let. Většina lidí vnímá software jako abstraktní vrstvu, ale mě vždy zajímalo, jak věci fungují pod kapotou ve fyzickém světě. Vystudoval jsem slaboproudou elektrotechniku v Děčíně, kde jsem pracoval s obvody, signály a hardwarem.

Při programování se proto soustředím na přehlednou architekturu, předvídatelné chování systémů a kód s minimální režií. Paralelně se studiem Aplikace informatiky v přírodních vědách na ČVUT FJFI stavím backendové systémy a praktické AI pipeline.

Věřím v integraci jazykových modelů do reálného světa, ale stavím kolem nich robustní logiku a validaci, aby pracovaly spolehlivě a bez náhodného chování.

Když zrovna nekóduji, věnuji se fyzickým projektům a stavbě věcí, na které si lze sáhnout.

PyAresParse

Python 3.10.6 Gemini 2.5 Flash Lite ARES REST API v3 ISIR API httpx (Async HTTP/2) SQLite 3.37 Pydantic

Autonomní CLI pipeline a parser pro vytěžování českých rejstříků. Propojuje ARES REST API v3 a insolvenční rejstřík (ISIR), přes asynchronní httpx stahuje účetní závěrky ze Sbírky listin a pomocí modelu Gemini 2.5 Flash Lite provádí extrakci finančních tabulek (obrat, vlastní kapitál, výsledek hospodaření). Systém autonomně dohledává kontakty na management firem a exportuje validovaná data do formátovaného XLSX.
